# Ось 4 — Local Sentiment Strain

> **Prizolov Lab** · Destination Readiness · Автор: Dm.Andreyanov · Версия: v0.1.0-draft

## Что измеряет
Уровень напряжённости между жителями и туристами — не мнение туристов о месте, а мнение жителей о туристах.

## Формула
```
Local Sentiment Strain = (Protest Activity × 0.4)
                        + (Local Media Tone × 0.3)
                        + (Policy Petition Signal × 0.3)
```

### Protest Activity (вес 0.4)
```
Protest Activity Score = число публичных акций по теме туризма за 12 мес × 12, потолок 100
```

### Local Media Tone (вес 0.3)
Только локальные издания на языке страны (не туристические СМИ/блоги).
```
Media Tone Score = доля статей за квартал с явно негативной рамкой ("overtourism", "turismofobia")
                    среди всех статей о туризме в топ-3 локальных изданиях
```
Каждый балл обязан цитировать конкретные заголовки в отчёте.

### Policy Petition Signal (вес 0.3)
```
Petition Signal = (подписи под активными петициями) / (население города) × 1000, потолок 100
```
Нормировка на население обязательна.

## Явно исключено из оси
- Отзывы туристов о встрече с местными (это опыт туриста, не настроение жителя)
- Комментарии в соцсетях без верификации (риск ботов/накрутки)
- Мнение туристических офисов (структурный конфликт интересов)

## Источники данных
- ACLED API — протесты
- News API / GDELT — локальные СМИ
- Change.org и муниципальные порталы петиций

## Автоматизация
Требует trust-tier механизма — Protest Activity объективна и автоматизируется быстрее, Media Tone требует LLM-классификации тональности с человеческой проверкой на старте.

## Пример расчёта (иллюстративно)
```
Барселона:
Protest Activity: 8×12=96 → 96
Media Tone: 45% → 45
Petition Signal: 15000/1.6M×1000=9.4 → 9.4

Strain = 96×0.4 + 45×0.3 + 9.4×0.3 = 54.7 → «Повышенное напряжение»
```
