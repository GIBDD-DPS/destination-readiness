# Ось 3 — Wait Time Burden

> **Prizolov Lab** · Destination Readiness · Автор: Dm.Andreyanov · Версия: v0.1.0-draft

## Что измеряет
Реальное (не заявленное) время ожидания в очереди к самым посещаемым объектам города.

## Формула (на уровне одного объекта)
```
Wait Time Burden = (Peak Wait Time / Acceptable Threshold) × 100, потолок 150
```

| Тип объекта | Acceptable Threshold |
|---|---|
| Музей/галерея | 30 мин |
| Достопримечательность под открытым небом | 45 мин |
| Общественный транспорт (пиковый час) | 10 мин |
| Ресторан без брони | 40 мин |

## Городской балл — максимум, не среднее
```
City Wait Burden = max(Wait Time Burden по топ-5 объектам)
worst_offender = объект с этим максимумом
```
Максимум используется намеренно: турист планирует маршрут по конкретным местам, усреднение по всем объектам города скрывает главную проблему.

## Источники данных
1. Google Popular/Busy Times — паттерн загруженности по часам
2. Отзывы с указанием даты/времени посещения (TripAdvisor, Google Maps)
3. Booking-системы time-slot (Саграда Фамилия, Колизей) — разница «есть слоты сегодня» vs «расписано на 3 недели» как точный прокси

## Автоматизация
Частично партнёрская — где объект продаёт time-slot бронирования, это готовый API. Там, где такой системы нет, ось помечается `not_applicable` — это не «нет проблемы», а «неизмеримо этим методом».

## Обязательное поле
`not_applicable` для открытых пространств без входного контроля (парки, улицы) — не 0.

## Пример расчёта (иллюстративно)
```
Барселона, август:
Саграда Фамилия: 90/45 = 200%, потолок 150 → 150
Парк Гуэль: 50/45 = 111 → 111
City Wait Burden = max(150, 111) = 150, worst_offender = "Саграда Фамилия"
```
