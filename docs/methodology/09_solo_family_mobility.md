# Ось 9 — Solo / Family / Mobility Barriers

> **Prizolov Lab** · Destination Readiness · Автор: Dm.Andreyanov · Версия: v0.1.0-draft

## Что измеряет
Физическая и социальная приспособленность направления под конкретный состав путешественников. Не входит в общий скор направления — показывается только если применимо.

## Условия показа (входные данные формы)
```python
is_solo = adults == 1 and children == 0
has_children = children > 0
mobility_flag: bool  # чекбокс, по умолчанию выключен, независим от состава группы
```

## Формула (общая для каждого профиля)
```
Profile Friction Score(profile) = Σ (weight_i × barrier_i) для факторов, релевантных профилю
```

| Профиль | Факторы | Источник |
|---|---|---|
| Solo | освещённость туристических зон, отзывы о безопасности одиночных поездок | муниципальные отчёты + фильтр отзывов |
| Family | пеленальные комнаты, инфраструктура для колясок | family-friendly фильтры агрегаторов, данные по тротуарам |
| Mobility | доступность транспорта, лифты в метро | accessibility maps транспортных операторов |

## Автоматизация
Частичная — accessibility-датасеты операторов транспорта дают основу, но требуют периодической ручной верификации (данные устаревают, стройки меняют доступность).

## Методологическое ограничение
Выдаётся не единый балл 0-100, а список конкретных барьеров с источником — сравнение направлений друг с другом здесь менее полезно, чем абсолютный чек-лист по конкретному городу.
