# Destination Readiness

Независимая методология и сервис оценки готовности туристического направления к поездке — по датам, а не по городу вообще. Не связан с проектом Agenomics — отдельный продукт с собственной архитектурой.

## Идея

Существующие рейтинги направлений (отзывы, рейтинги отелей) не показывают структурных проблем: перегруженность инфраструктуры в конкретный месяц, риск новых ограничений, реальное время в очереди, напряжённость между жителями и туристами, ценовые аномалии. **Destination Readiness** — 13 независимых осей + персональный блок Trip Cost & Feasibility, каждая со своей формулой, источником данных и обязательной причиной (`reason`) для присвоенного значения.

## Статус проекта

`v0.1-draft` — методология и прототип дашборда готовы, бэкенд в стадии каркаса (см. `backend/`).
