# Ось 1 — Infrastructure Load

> **Prizolov Lab** · Destination Readiness · Автор: Dm.Andreyanov · Версия: v0.1.0-draft

## Что измеряет
Отношение туристического потока к пропускной способности инфраструктуры города (вода, транспорт, медицина, жильё) в конкретный месяц.

## Формула

```
Load Index = (Tourist Density Ratio × 0.4)
           + (Accommodation Saturation × 0.3)
           + (Transit Strain × 0.3)
```

### Tourist Density Ratio (вес 0.4)
```
Tourist Density Ratio = среднесуточное число туристов в месяце / постоянное население города
```

| Соотношение | Балл 0-100 |
|---|---|
| < 0.5 | 20 |
| 0.5 – 1.5 | 40 |
| 1.5 – 3.0 | 65 |
| 3.0 – 5.0 | 85 |
| > 5.0 | 100 |

### Accommodation Saturation (вес 0.3)
```
Accommodation Saturation = ночей, забронированных туристами за месяц / (номерной фонд × дни в месяце)
```

### Transit Strain (вес 0.3)
Прокси на MVP-этапе — загрузка главного аэропорта/вокзала относительно проектной мощности.

## Источники данных
- Муниципальная туристическая статистика (открытые данные Барселоны, Венеции и т.п.)
- Национальные статбюро / Eurostat — население
- Годовые отчёты аэропортов — проектная мощность
- STR/CoStar (платно) или муниципальные дашборды по краткосрочной аренде — occupancy

## Автоматизация
Численная, детерминированная ось. Автоматизируется полностью при подключении open-data API муниципалитета — ручной труд нужен только для городов без открытой статистики.

## Пример расчёта (иллюстративно)
```
Барселона, август:
Tourist Density Ratio: 1.8M / 1.6M = 1.1 → балл 40
Accommodation Saturation: 92% → балл 85
Transit Strain: 115% от проектной мощности → балл 90

Load Index = 40×0.4 + 85×0.3 + 90×0.3 = 68.5 → «Высокая нагрузка»
```
